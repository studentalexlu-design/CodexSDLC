# guidelines/ — 團隊開發規範

本目錄屬於專案，升級不覆蓋。安裝時附帶的 `api.md`、`sql.md`、`coding.md`、`testing.md`、`rules.json` 均為範例，請改寫為團隊規範；不需要時可整個刪除。

寫法、讀取對象、`rules.json` 格式與由審核歸納規範的方式，見 [`.codex/bdd-workflow/guidelines-guide.md`](../.codex/bdd-workflow/guidelines-guide.md)（隨 `update` 更新）。

本檔未經修改時，`update` 會換成新版；修改後即不再變動。
