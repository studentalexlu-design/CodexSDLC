## 設定面板

活動列的 **Codex SDLC** 圖示 → 「設定」：

- **狀態**：版本、hooks 信任、有沒有新版、需要處理的事
- **Agent 調校**：每個 agent 的 effort／model。點一下就能改；需要套用的會標 ●，改完按一次「套用」
- **審核**：修正輪上限（不必套用，下一次委派就生效）
- **更新**：檢查頻率、來源
- **規範**：規範文件、`rules.json`（存檔時自動驗）、機械層開關
- **這台機器**：pwsh 與 codex 的位置

所有修改都經過 `sdlc.ps1 set`：先驗完才寫，寫錯一個字都不動。直接改 `sdlc.config.json` 也可以 —— 編輯器會有補全與錯字提示，檔案上方有「套用」按鈕。

`sdlc.config.json` 不支援註解；要寫說明請寫在 `_note`。
